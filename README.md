# GraphRAG News Assistant

Комплексная система анализа и агрегации новостей из Telegram-каналов на базе гибридного RAG-подхода (Graph + Vector Retrieval).

## Описание проекта

Система предназначена для автоматического сбора, структурирования и глубокого анализа новостного контента. В отличие от классических RAG-систем, данный проект использует комбинацию векторного поиска и графовых баз данных, что позволяет выявлять скрытые взаимосвязи между событиями и проводить семантический анализ длинных цепочек новостей.

## Ключевые возможности

- Автоматизированный сбор данных через Telegram API (MTProto).
- Сегментация текста на смысловые сегменты (чанки) с сохранением контекста.
- Построение динамического графа знаний в автоматическом режиме.
- Хранение и поиск по векторным представлениям текстов (Embeddings).
- Оркестрация процессов обработки данных через Apache Airflow.
- Мониторинг и логирование экспериментов с помощью MLflow.

## Режимы работы аналитического бота

Система поддерживает три специализированных режима взаимодействия:

1. **Режим 1: Фактологический поиск (Fact Search)** — прямой ответ на вопрос пользователя на основе данных из локальной базы знаний. Применяется для быстрого извлечения конкретных фактов и событий.
2. **Режим 2: Трансверсальный анализ (Cause-Effect)** — использование графовых связей для поиска причинно-следственных связей. Система анализирует, как события в одной отрасли влияют на другие сектора экономики или политики.
3. **Режим 3: Аналитический дайджест (Summary Mode)** — генерация структурированной выжимки событий за выбранный период по конкретной теме. Включает в себя механизм жесткой фильтрации нерелевантного контента (Sector Lockdown) и группировку дублирующих новостей.

## Технологический стек

- **Язык программирования**: Python 3.11
- **LLM**: Google Gemini API
- **Векторное хранилище**: Qdrant (векторный поиск)
- **Графовая БД**: Neo4j (хранение сущностей и связей)
- **Реляционная БД**: PostgreSQL (метаданные и статусы каналов)
- **Оркестрация**: Apache Airflow
- **Телеметрия**: MLflow
- **Контейнеризация**: Docker / Docker Compose

## Особенности сетевой архитектуры

Для обеспечения стабильного доступа к API нейросетей из регионов с ограниченным доступом реализована архитектура Sidecar Proxy. 

- В состав Docker-окружения включен сервис `finland_proxy` на базе Xray.
- Весь HTTP/HTTPS трафик аналитических сервисов (Gemini API) маршрутизируется через данный шлюз.
- Это решение обеспечивает автономность системы и исключает зависимость от сетевого окружения хоста. 
- Примечание: для работы протоколов прямого соединения (MTProto Telegram) может требоваться дополнительная настройка сетевых интерфейсов или использование VPN-шлюза на стороне хост-системы.

## Установка и запуск

1. Склонируйте репозиторий.
2. Настройте файлы конфигурации `.env.db` и `.env.scraper` (используйте шаблоны в корне проекта).
3. Запустите систему:
```bash
docker-compose up -d
```
